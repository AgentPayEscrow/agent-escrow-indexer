# Contributing to Agent Escrow Backend

## How to Contribute

1. Fork the repository
2. Create a branch
3. Run `npm install`
4. Make your changes
5. Run `npm run test`
6. Commit and push
7. Open a Pull Request

## Issue Points (Drips Wave)

| Difficulty | Points |
|------------|--------|
| Easy | 100 |
| Medium | 150 |
| Hard | 200 |

## Pull Request Requirements

- Title must include `Closes #issue_number`
- Tests must pass
